# GS_EasyImageUploader
An App Script for Google Sheets to help with bulk inserting images into cell.




HOW TO

on your google sheet of choice go to

Top Bar
  Extensions
    App Script
    (Should Open up a new project)
    
      Replace the Code.gs with this project's "Code.gs"

        Create a new File - Type: 'HTML'
          Make sure it is named "Dialog.html"
            Fill its contents with this project's "Dialog.html"

            Name the Project "Easy Image Uploader" or whatever

              Hit the Floppy Disk with Google Hexagon symbol to Save.
